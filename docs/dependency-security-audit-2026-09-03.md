## Evidencia

- `npm ls` resuelve exactamente `@humanfs/node@0.16.8`, `browserslist@4.28.8`, `dompurify@3.4.14`, `fast-uri@3.1.7`, `nanoid@3.3.18`, `postcss-selector-parser@6.1.4` y `uuid@11.1.1`.
- Una corrida online completa de `npm audit` devolvió 0 hallazgos. Para descartar un falso cero del caché offline se consultó el mismo endpoint desde un proyecto aislado con `dompurify@3.3.0` y `nanoid@3.3.7`; allí devolvió 1 moderado y 1 alto.
- Una repetición posterior desde esta tarea agotó el timeout del endpoint bulk de npm. No se interpretó ese error de red como un resultado de seguridad ni se usó el `--offline` sin advisories.
- DOMPurify y ExcelJS tienen pruebas de runtime directas. Los cinco overrides exclusivos del toolchain se ejercitan indirectamente con lint, type-check y build.
- `node_modules/.deno/` conserva una caché interna con un `uuid@8.3.2`, pero no pertenece al grafo de `package-lock.json`, no aparece en `npm ls` y no entra al bundle. Es higiene local, no un hallazgo pendiente del producto.

## Rollback

La remediación está concentrada en `package.json` y `package-lock.json`: una dependencia directa y seis overrides explícitos. No hubo `audit fix`, migración de datos, deploy ni actualización masiva de majors.
